# 学习控制台近期活动与强化入口实施计划

> **执行要求：** 使用测试驱动开发，所有统计必须来自当前令牌用户的后端数据。

**目标：** 控制台展示真实累计统计、最近练习、最近考试、近期正确率趋势、最新薄弱知识点和定向强化入口，不使用静态样例或客户端伪造数据。

**架构：** `exam-service` 从统一学习作答记录中按练习批次生成脱敏摘要；考试历史继续复用 `/exams`，报告趋势和薄弱点继续复用 `/reports/learning`。Vue 控制台并行读取这些接口并分别处理空状态，强化链接携带知识点进入练习中心。
