# 服务端可信学习报告、历史趋势与强化建议实施计划

> **执行要求：** 使用测试驱动开发；先观察失败，再实现并完成真实 MySQL 验收。

**目标：** 报告只使用当前登录用户真实的练习和考试逐题记录，展示总体正确率、知识点与题型表现、近期趋势、历史报告和具体强化题目；客户端不能伪造对错样本。

**架构：** `exam-service` 新增统一学习作答记录仓库，练习提交和考试首次完成时写入不可变题目快照。`report-service` 依赖该只读契约，按令牌用户聚合并保存报告快照；详细统计以 JSON 快照存入现有 `learning_reports` 表，核心字段继续可索引。强化题从当前正式题库按最薄弱知识点选取，响应不包含答案。

**技术栈：** Java 17、Spring Boot、Spring JDBC、MySQL、Jackson、Vue 3、TypeScript、Vitest。
