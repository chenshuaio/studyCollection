# PDF 学习资料上传设计

**日期：** 2026-08-02

**目标：** 用户可以上传含可复制文字的 PDF 格式 Java 学习资料，系统提取正文并生成可编辑题目预览；用户确认后提交管理员审核。

## 范围

- PDF 只进入“学习内容生成题库”流程，不作为结构化题目文件解析。
- 支持具有文本层、可以正常复制文字的 PDF。
- 不支持扫描版或纯图片 PDF，不增加本地 OCR 或在线视觉识别。
- 单个文件最大 10 MB，与结构化题目文件上传限制保持一致。
- 生成题目仍遵循现有个人题库/申请公开范围和管理员审核流程。

## 前端交互

“上传 Java 学习资料”入口明确显示支持 `PDF / DOCX / XLSX / CSV / MD / TXT`，文件选择器继续接受 `application/pdf` 和 `.pdf`。

选择 PDF 后，前端先检查扩展名和 10 MB 大小限制。合法文件以 `multipart/form-data` 上传到 `POST /imports/knowledge/upload`。上传期间显示正在解析状态，成功后将后端返回的题目放入现有可编辑预览表格，不自动提交审核。

用户可以修改题干、题型、难度、知识点、答案和解析。点击提交审核后，当前预览题逐题进入待审核列表。

## 后端处理

`KnowledgeFileTextExtractor` 负责统一验证资料文件并按扩展名提取文本：

1. 拒绝空文件、超过 10 MB 的文件和未支持的扩展名。
2. 使用 Apache PDFBox 读取 PDF 文本层。
3. 对提取结果执行空白检查，再交给 `KnowledgeQuestionGenerator`。
4. 保留现有 DOCX、XLSX、CSV、Markdown 和纯文本处理能力。

后端不依据客户端 MIME 类型单独放行文件，以文件扩展名白名单和实际解析结果共同判断，避免浏览器 MIME 差异影响正常上传。

## 错误处理

- 空文件：`学习资料文件不能为空。`
- 文件超过 10 MB：`学习资料文件不能超过 10 MB。`
- 扫描版或纯图片 PDF：`PDF 未提取到可用文字，请上传可复制文字的 PDF，扫描版暂不支持。`
- 损坏或受密码保护的 PDF：`PDF 无法解析，请确认文件未损坏且未加密。`
- 不支持的格式：返回支持格式列表。

以上校验错误通过现有统一异常处理返回 HTTP 400，前端直接展示中文消息，不清空已经生成的预览题目。

## 测试与验收

后端自动测试覆盖：

- 文本型 PDF 能提取内容并生成题目。
- 空白 PDF 返回扫描版提示。
- 损坏或加密 PDF 返回可理解的 400 错误。
- 超过 10 MB 的 PDF 被拒绝。
- 不支持的文件扩展名被拒绝，原有格式仍可解析。

前端自动测试覆盖：

- 学习资料入口明确展示 PDF 支持并保留 `.pdf`、`application/pdf` 接受类型。
- 大于 10 MB 的文件在前端被拒绝且不发起请求。
- PDF 上传成功后展示可编辑预览，不直接入库。
- 后端 PDF 错误消息能够展示给用户。

最终使用实际文本型 PDF 在本地 MySQL 模式完成上传、生成预览和提交审核验证，并检查桌面与手机宽度下上传控件和提示文本可用。
