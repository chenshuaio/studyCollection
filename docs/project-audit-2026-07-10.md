# StudyCollection 项目审计（更新于 2026-07-11）

## 本轮整改结果

- 后端增加统一令牌认证，除登录和注册外的接口必须登录。
- 题库写入、删除、审核、知识点和用户管理接口增加后端管理员权限校验。
- 登录和注册返回完整用户身份；前端统一携带 Bearer token，不再使用硬编码用户编号。
- 练习、错题、反馈、统计均以令牌中的用户编号为准，客户端不能伪造其他用户身份。
- 普通用户查询题库时隐藏答案与解析；评分从服务端题库读取标准答案，不再信任客户端答案快照。
- 新密码使用 PBKDF2 加盐哈希，旧 `{plain}` 演示账号登录后自动升级。
- 令牌增加 12 小时有效期、恒定时间签名比较和声明转义；未配置密钥时每次启动生成随机密钥。
- MySQL 模式新增练习统计、错题、待审核题、反馈与修订持久化，解决重启后控制台数据清空问题。
- 可预期业务校验错误统一返回 HTTP 400 和 `VALIDATION_FAILED`，不再冒成 500。
- 单选、判断和多选题恢复选项按钮且默认不选择；多选答案按选项集合归一化，不受点击顺序和中英文分隔符影响。
- 待审核题与反馈增加状态流转保护，重复点击不会再次入库或重复审核；跨表审核操作使用事务。
- 管理员删除题目改为软删除，题目不再进入搜索、练习和判分，同时保留既有反馈、修订与历史关联。
- 自定义考试改为服务端会话：试卷、题目快照、已保存答案、开始/截止时间、提交结果和考试历史均持久化到 MySQL。
- 考试答题页按服务端剩余时间倒计时，逐题自动保存，刷新或重新登录后可以恢复；超时会使用截止前已保存答案自动提交。
- 考试会话按令牌用户隔离，提交前隐藏题目快照中的答案与解析，重复提交保持幂等，不会重复累加学习统计。
- 简答题和编程题按设计只保存用户答案，提交后展示参考答案和解析，不自动评分、不计入客观题满分，也不会自动进入错题本。
- 练习中心新增服务端随机生成接口，支持按知识点、难度、题型和 1-100 道数量组合筛选；返回题目不包含答案和解析。
- 练习页支持多题逐题作答、进度显示和完成小结，同时保留错题本单题重练入口。
- 学习统计拆分为已作答、可自动评分和答对数量，控制台正确率不再把简答题、编程题计入分母。
- 结构化题目文件新增独立上传接口，JSON、CSV、XLSX、Markdown 和 TXT 可批量映射完整题目字段，PDF/DOCX 等资料继续走知识内容分析出题。
- 导入预览和资料生成预览均可编辑题干、题型、难度、知识点、答案和解析，也可新增或删除候选题，确认后才进入管理员审核队列。
- 前端加入 `vue-tsc` 严格类型检查，并纳入统一验证脚本；同时修正考试计时器、反馈响应和测试夹具中的类型契约偏差。
- 练习和考试首次完成时统一保存逐题作答快照，记录服务端题干、题型、难度、知识点、用户答案、评分结果和作答时间；重复考试提交不会重复写入。
- 学习报告不再接受客户端传入的对错样本，只按当前令牌用户的真实作答聚合；主观题计入作答量但不进入客观正确率分母。
- 报告新增知识点表现、题型表现、近七个学习日趋势、历史快照和最多五道脱敏强化题，历史与作答明细均持久化到 MySQL。
- 报告页支持规则/在线模型模式、历史切换和薄弱知识点定向练习，并通过 1280px 与 390px 浏览器布局验证。
- 学习控制台新增真实最近练习批次、最近考试、最新报告趋势和薄弱知识点强化入口；单个数据源失败不会阻断其他面板展示。

## 仍需继续完善

### 高优先级

- 题目修订记录尚未保存完整修改前/后快照，报告也未标识或排除已确认答案错误的历史题目。

### 中优先级

- 在线模型当前是通用 HTTP 适配器，尚未提供 OpenAI 兼容响应解析、模型配置页面和调用审计。
- 题目选项仍内嵌在题干文本中，`question_options` 表尚未成为统一读写模型。
- 管理员驳回或待复核备注尚未单独持久化展示。
- 当前本地版用一个 Spring Boot 进程聚合模块；设计中的独立网关和服务路由尚未拆分。
- 当前令牌是自有 HMAC 签名格式，不是设计文档指定的标准 JWT；正式在线部署前应迁移到成熟 JWT/OIDC 方案。
- 昵称重复由应用层校验，MySQL 尚未建立唯一索引，并发注册仍存在竞争窗口。
- 考试会话的重复提交和超时结算目前依赖本地单实例服务内同步；若后续拆成多实例，需要增加数据库条件更新或分布式锁。

## 当前可用边界

本地 MySQL 模式已具备安全登录、结构化题目导入、学习资料出题、管理员审核、公共题库、条件随机多题练习、服务端客观题评分、主观题参考答案、自定义组卷、考试进度恢复、错题与反馈、控制台统计、可信报告历史、学习趋势和规则/在线回退分析闭环。它仍是第一阶段开发版本，管理员考试规则、个人题库、完整题目版本影响处理和标准在线模型配置尚未完成。
